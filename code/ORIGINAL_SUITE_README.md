# Gated Sequential Testing — Experimental Benchmark Suite

This package is the reproducibility companion for **Evidence-Gated Sequential Binary Testing: Certification Ladders under Endogenous Experiment Availability**.

The experiments are organized around the manuscript's actual claims rather than generic ML benchmarks:

1. exact binary theorem validation;
2. record-envelope / LP verification and deeper ladders;
3. exploratory 3/5/10-hypothesis extensions;
4. robustness outside the formal assumptions;
5. external sequential-sensing replay on UCI HAR, with a PRISM robotics follow-on protocol.

## Notebooks

| Notebook | Purpose | Claim status |
|---|---|---|
| `01_binary_theory_benchmarks.ipynb` | Lower bound, first-order convergence, PoC, baselines, false unlock, terminal errors, finite-confidence gap | **Formal-theory validation** |
| `02_record_envelope_lp_ladders.ipynb` | Non-monotone requirements, LP equality, L=2/3/5/10 sequential ladders, epistemic trap | **Formal-theory / structural validation** |
| `03_multihypothesis_extension.ipynb` | N=3/5/10, uniformly-hardest case and hardest-alternative switching | **Exploratory extension** |
| `04_robustness_stress_tests.ipynb` | Gaussian, AR(1) dependence, misspecification, overshoot | **Outside-assumption robustness** |
| `05_external_uci_har_replay.ipynb` | Public-data weak/strong sensing replay; six-class extension | **External instantiation, not physical-safety validation** |

## Execution modes

### 1. Smoke verification

```bash
python run_all.py --mode smoke
```

- small Monte Carlo;
- no internet required;
- external notebook uses a deterministic mock sensor dataset only to validate code paths;
- **never report smoke numbers in the paper**.

### 2. Standard benchmark

```bash
python run_all.py --mode standard
```

- moderate Monte Carlo;
- external notebook downloads the official UCI HAR dataset if it is not cached;
- suitable for iteration and plot inspection, not rare-event publication claims.

### 3. Publication-scale benchmark

```bash
python run_all.py --mode full
```

- larger trial counts;
- intended to generate paper/supplement results;
- rare-event probabilities still require checking that the number of observed events is large enough for meaningful intervals.

You can also open each notebook in Colab/Jupyter. `FULL_RUN=1` enables publication-scale settings; `SMOKE_TEST=1` forces the small offline validation path.

## Output directories

- `results/`: CSV/JSON tables.
- `figures/`: publication-ready plot files generated by notebooks.
- `src/`: shared simulation and statistical utilities.
- `tests/`: unit tests for KL, lower-bound, LP, simulation and metric invariants.

## Statistical reporting rules

For paper results:

- report mean stopping time with 95% CI;
- report median and 95th percentile stopping time;
- report H0 and H1 decision errors separately;
- report false-unlock and failed-unlock probabilities with Wilson intervals;
- report stage-specific sample counts;
- show `E[tau]/log(1/delta)` against `C_gate`;
- distinguish finite-sample empirical PoC from the first-order theoretical PoC;
- use >=10,000 trials for main synthetic configurations where feasible;
- increase trials substantially for claims about probabilities near 1e-4 or 1e-5.

## Scope guardrails

The matched theorem is binary, nested, irreversible, conditionally independent and known-model. The Gaussian, correlation, misspecification, six-class UCI and hardest-alternative-switching experiments are intentionally broader. They are evidence about robustness or extensibility, **not proofs that the existing theorem covers those regimes**.

The UCI HAR study is an **external sequential-sensing replay**: accelerometer-derived features are the weak sensing channel and accelerometer+gyroscope features are the strong channel. It demonstrates that the gating machinery can be instantiated with estimated sensor-conditioned models. It is not physical-safety validation.
